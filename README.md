# হিসাব খাতা

মোবাইল থেকে চালানোর জন্য ব্যবসার হিসাব-নিকাশ ওয়েব অ্যাপ। GitHub Pages এ ফ্রি হোস্ট হবে, ডেটা Firebase-এ আজীবন সেইভ থাকবে।

## ধাপ ১ — Firebase প্রজেক্ট তৈরি

1. মোবাইল ব্রাউজারে যান: https://console.firebase.google.com
2. **Add project** → নাম দিন (যেমনঃ `hisheb-khata`) → Continue → Google Analytics অফ রাখতে পারেন → Create project
3. প্রজেক্ট খোলার পর বাম পাশের মেনু থেকে **Build → Authentication** → **Get started**
4. **Sign-in method** ট্যাবে গিয়ে **Email/Password** চালু করুন (Enable → Save)
5. **Users** ট্যাবে গিয়ে **Add user** — এখানে নিজের ইমেইল ও একটা পাসওয়ার্ড দিন। এটাই দিয়ে অ্যাপে লগইন করবেন।
6. বাম মেনু থেকে **Build → Firestore Database** → **Create database** → Production mode → লোকেশন যেকোনো একটা কাছেরটা বেছে নিন → Enable

## ধাপ ২ — সিকিউরিটি রুলস বসান

Firestore Database পেজে **Rules** ট্যাবে যান, এই প্রজেক্টের `firestore.rules` ফাইলের ভেতরের পুরো লেখাটা কপি করে সেখানে পেস্ট করে **Publish** চাপুন। এতে করে শুধু আপনি নিজের ডেটা দেখতে/বদলাতে পারবেন, অন্য কেউ পারবে না।

## ধাপ ৩ — ওয়েব অ্যাপ কনফিগ নিন

1. প্রজেক্ট Overview পেজে (⚙️ আইকনে ক্লিক করলে **Project settings**) নিচের দিকে **Your apps** সেকশনে যান
2. `</>` (Web) আইকনে ক্লিক করুন → অ্যাপের একটা নাম দিন (যেমনঃ hisheb-khata-web) → Register app
3. যে কোড দেখাবে তার ভেতর থেকে `firebaseConfig` অবজেক্টটা কপি করুন — এরকম দেখতে হবে:
   ```js
   const firebaseConfig = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     ...
   };
   ```
4. এই প্রজেক্টের `js/firebase-config.js` ফাইলটা খুলুন, ওখানে যে `firebaseConfig` আছে সেটার জায়গায় আপনার কপি করা ভ্যালুগুলো বসান।

## ধাপ ৪ — GitHub এ আপলোড

1. GitHub এ নতুন একটা রিপো বানান (যেমনঃ `hisheb-khata`) — Public রাখুন
2. এই ফোল্ডারের সবগুলো ফাইল (index.html, login.html, folders.html, folder.html, loans.html, css/, js/, firestore.rules, README.md) রিপোতে আপলোড করুন
   - মোবাইলে হলে GitHub অ্যাপ/সাইট থেকে **Add file → Upload files** দিয়ে সব ফাইল একসাথে টেনে দিতে পারবেন (ফোল্ডার স্ট্রাকচার ঠিক রেখে)
3. রিপোর **Settings → Pages** এ যান → Source: **Deploy from a branch** → Branch: `main` / root → Save
4. কিছুক্ষণ পর লিংক পাবেন — `https://YOUR-USERNAME.github.io/hisheb-khata/`

## ধাপ ৫ — Firebase-কে এই ঠিকানা চেনান (জরুরি)

Firebase Console → Authentication → **Settings** ট্যাব → **Authorized domains** → **Add domain** → লিখুন:
```
YOUR-USERNAME.github.io
```
এটা না করলে লগইন কাজ করবে না।

## ব্যবহার

- প্রথমে `login.html` এ আপনার তৈরি করা ইমেইল/পাসওয়ার্ড দিয়ে ঢুকবেন
- **হিসাব-কিতাব** পেইজে + চেপে কাস্টমারের নামে নতুন ফোল্ডার বানান
- ফোল্ডারের ভেতরে + চেপে প্রোডাক্ট/ক্যাটেগরি যোগ করুন — পরিমাণ, মূল রেট, কাস্টমার রেট দিলে খরচ/বিক্রয়/লাভ অটো হিসাব হবে
- নতুন ক্যাটেগরি একবার যোগ করলে পরের যেকোনো ফোল্ডারে সেটা লিস্টে থাকবে
- **"পরিশোধ"** না চাপা পর্যন্ত লাভ শুধু ফোল্ডারেই দেখাবে, মূল ব্যালেন্সে যোগ হবে না
- **ঋণের হিসাব** পেইজে কে কত টাকা পাবেন তার আলাদা তালিকা রাখতে পারবেন, আদায় হলে "আদায় হয়েছে" চাপলে ব্যালেন্সে যোগ হবে
- হোম পেইজে **"গ্রহণ / উত্তোলন"** চেপে যা তুলবেন তা বাবদসহ লিখলে মূল ব্যালেন্স থেকে কেটে যাবে

## খরচ

Firebase-এর ফ্রি (Spark) প্ল্যান এবং GitHub Pages — দুটোই স্থায়ীভাবে ফ্রি, এই ব্যবহারের পরিমাণে (একজন ব্যবহারকারী, কয়েকশো/হাজার এন্ট্রি) কোনোদিন টাকা লাগবে না।
